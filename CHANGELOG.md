## 3.0.0

### General
- Reworked ladder crafting: recipes are no longer strictly tier based - each ladder can be crafted independently.
- Added the Styler Tool: switches ladder model variants (currently 4 model types available).
- Reworked upgrade items: upgrades are now tools that consume charges (e.g. the Light Tool uses 1 Glowstone Dust per ladder).
- Removed the Power Upgrade. Added a Sensor Tool that detects climbing entities and emits a redstone signal.
- Removed the Refined Iron Ladder.
- Removed ladder upgrades.
- Reworked ladder speed system (config + logic).
- Improved loading time (previously the game could take 30+ seconds to load with the mod installed).
- Updated all `en_us` and `ru_ru` translations.
- Improved tool interactions.

### Visual
- Updated textures for all ladders.
- Added multi-variant textures (small randomized visual differences, e.g. highlights/tint variation).
- Updated ladder models.

### Compatibility
- Fixed incompatibility with ModernFix.
- Added compatibility with WTHIT.
